## 사용 방법과 실제 구현

메인 → 현대 국가 모드 → 독립 지역 규칙 → 본국/지역 선택 → AI 비중·목표·규칙
→ 시작이다. 당시 구현은 Q/W/E로 군종을 고르고 좌클릭/드래그로 선택한 뒤,
우클릭 미리보기와 별도 실행을 요구했다. **현재 복구판은 선택한 부대의 커서
목적지를 미리 보여주고 우클릭으로 이동·공격을 즉시 확정한다.** Shift+우클릭은
후속 명령을 추가한다. 화면·터치 조작을 포함한 현재 사용법은
[직접 지휘 안내](RepairUI.md#선택과-경로)를 따른다.
게임의 저장 메뉴는 실제 snapshot 저장·이어하기·재시작을 제공하며 결과의
복습은 기존 리플레이를 연다. 도움말에서 현대 8개 선택형 실습을 시작한다.

10 tick=1 게임초다. 수치 설정은 `ModernRules.ts`/`ModernForceTypes.ts`, 행정·기후·항구
입력과 재생성은 `map-generator/modern-world-v2`에 있다. 지리 면적과 타일 수는
구분하며 면적 득점은 지역 실제 면적을 해당 유효 타일에 배분한 근사치다.
지도 거리의 투영 왜곡까지 제거하지 않았다.

민간 → 가용 인력 → 군종 편성은 기존 인구를 이동시키며 인구를 새로 생성하지
않는다. 자연 출생 증가는 이번 규칙에 없다. 최후 영토 상실 때 패배 세력의
민간·가용 인력을 승자에게 한 번 이전하며 군 손실은 사망 회계에 남긴다.
일부 영토만 점령하거나 이미 이전한 세력을 다시 처리해 N0를 복제하지 않는다.
가용 인력 상한은 현재 인구 5%, 육군 동원 상한은 10%이며 보충과 훈련에도
시간·인력·자금 한도가 적용된다.
전용 교육에서는 모든 세력의 공통 시작 자금을 4,000,000으로 공개 설정하고
실습 상대·필요 시설을 준비한다. 일반 경기의 400,000과 구분한다.

## 실행한 검사

- 최종 `npm run build-prod` 및 `npm run lint` 통과. 기존 큰 번들 경고는 남는다.
- Windows portable 한 번의 회귀 실행: 607파일·7,644검사 통과·1 skip, 307.24초.
  원래 POSIX 배포 셸을 요구하는 6개 파일은 제외했다. `npm test` 전체가 Windows에서
  통과했다는 주장과 구분한다. 후속 군집·저장·교육 수정은 해당 검사로 재검증했다.
- core 검사에는 실제 attack/transport/warship 실행, 마지막 손실 및 철수 인력,
  보호된 목표, 양쪽 기후·전투 미리보기, 항구 점령·개발·피해·복구·봉쇄, 실제
  MIRV 발사 단위·누적/만료, command 권한·schema/binary, snapshot migration과
  복원 이후 미래 상태, replay keyframe/역방향 탐색이 포함된다.
- 군사·AI 최종 36개, 군사/native 회귀 묶음 180개, 교육 53개, 저장/클라이언트
  65개, HUD/runner 14개, 서버/연결 171개는 각각 실행했다. 중복 검사이므로 이
  숫자들을 합쳐 전체 검사 수로 제시하지 않는다.

## 실제 브라우저 증거

Playwright CLI로 실제 Chromium UI를 조작했다. 진단은 읽기 전용 공개 상태,
저장은 실제 UI 내보낸 snapshot끼리 비교했다. 테스트용 게임 상태 주입이나
계정 API 모방은 사용하지 않았다.

- 대한민국 실제 국경 시작 → 군집 이동 → 북한 육상 공격 → 실제 점령/손실 →
  제한시간 패배 결과 → 복습 끝/앞/뒤 탐색 → 재시작을 확인했다. 러시아 `RUS-r01`
  선택에서는 전체 러시아 대신 한 독립 지역만 인간이고 나머지는 AI였다.
- 최종 빌드 `cbc190be72f55f98b4b0205046382afc387db4c3cad3d3fdc4fcb88bd8b5e599`
  대한민국 저장/이어하기/재저장의 tick5 전체 core canonical SHA-256은 양쪽
  `0f4ea1f518b6e7f1b0115f1d06824a55a1d417752ee89efe000f325a90f9d132`,
  현대 해시 4158208258 및 명령 기록이 일치했다. 직렬화 바이트의 키 순서 차이는
  의미 상태 동일성과 구분했다. 앞선 공격중 tick1261, 러시아 tick13과 실제
  핵 피격 tick2488도 각각 같은 빌드의 전체 core 일치를 확인했다.
- 같은 seed/`MR000001`의 새 판 두 개는 서로 다른 저장용 runId 자동 저장을
  실제로 보존했고 이어하기는 원래 runId를 유지했다. 구빌드 저장 거절·보존,
  파일 가져오기/새 이름 보존 및 UI 파일 내보내기를 확인했다.
- 실제 두 브라우저 초대방: 한국/일본 두 인간, 초대 AI 1개, 세계 AI 291개,

## 성능과 남은 제한

최종 AI 경기·시뮬레이션 측정 표와 실행 명령은
[측정 보고서](benchmarks/modern-v2/REPORT.md)에 있다. 기존 v1 NationExecution과
새 v2는 국가 수·소유권·인구·공군 규칙도 다르므로 전체 모드의 비용 비교다.
높은 수준 대 낮은 수준의 지역 경기와 기존 NationExecution 대 강화 AI의
앞선 육전 fixture는 별도 표본이다. 대전 종료 점수 승리를 완전 정복 승리라고
부르지 않는다.

최종 동일 코드 SHA-256은
`b76f47b090aa372de5c3e0be378fbe95e3f6e272f57275c0f8c06e6e2405a6e0`이다.
기본 혼합의 p50/p95는 20.58/99.83ms, 반복 p95는 106.68ms였다. 기존 v1
p95 51.85ms 대비 +92.5%(반복 +105.7%)로 요청한 20% 목표를 달성하지
못했다. 혼합 p99 163.75ms·최대 432.60ms·100ms 초과 60/1200 tick이며
표본 peak heap/RSS는 134.64/362.83MiB였다. 같은 기기의 fresh process로
측정했지만 한 seed의 초반 1200 tick이며 일반 저사양 성능 보장은 아니다.
기본 AI 확률 각 1/3을 유지했으며 기기 속도에 따라 판단을 생략하지 않았다.

4개 실제 지역 쌍 × 30 seed × 시작 위치 교환의 240경기는 상161승/하79승,
상 67.08%였다. 전부 3000 tick 제한시간의 순점령 면적 점수이며 완전 탈락
승리는 0이다. 지역별 상 승률은 한국/북한 96.67%, 독일/프랑스 55.00%,
알제리/리비아 분할 58.33%, 노르웨이/스웨덴 58.33%로 지리 편차가 남는다.
수정 전의 95.83%를 최신 결과로 사용하지 않았다. 이 비교는 현대 상 대 하이며
기존 NationExecution 상대 승률의 증거는 아니다. 앞선 강화 AI의 기존 AI
상대 육전 fixture는 [기존 보고서](EnhancedAI.md)에서 별도로 구분한다.

240경기 모두 살아 있는 인구+사망=2,000,000, 전세계 v2 프리셋은 294,000,000
보존과 군종 합계를 확인했다. 8개 seed0 경기 반복 해시가 모두 일치했고
혼합 캐시 유지/제거/반복의 현대 해시 364226041도 일치했다. 남은 영토가
있는데 인구만 0인 생존 세력은 없었다. 국경 후보/경로 한도 때문에 외딴 잔여
영토를 끝내 점령하지 못하는 교착은 남으며, 최후 영토 탐색·후반 시설 연결·
보존 군집 기록과 업데이트 비용을 다음 최적화 대상으로 기록했다.
240경기 중 59경기는 마지막 영토 변화 뒤 1,000 tick 이상이 지났다.
이 지표는 그동안 경제·전투·항공 임무가 전혀 없었다는 의미는 아니다.

한 브라우저의 5초 RAF 표본은 paused 91.12fps/p95간격24.20ms, running
70.19fps/p95간격30.10ms, JS heap 약207~208MiB였다. 다른 교육 브라우저가
활성 상태였으므로 GPU 렌더 비용·독립 비교·저사양 성능 통과의 근거가 아니다.

공개 API가 끊긴 preview에서는 기존 연결 오류 창을 닫은 뒤 로컬 게임을
진행한다. dev 초대 fallback은 검증된 loopback bootstrap 및 실제 binary WS
프레임에만 적용한다. 공개 인증·매치메이킹·랭킹을 구현했다고 주장하지 않는다.
실제 브라우저 storage quota 실패, 물리 기기, 모든 기존 심화 교육 완주/5~8분
소요시간, 전 테마·확대 가독성, 장기 네트워크 복구와 전세계 장시간 균형은
미검증이다. 전체 알림 우선순위·자동 패배 분석 차트·가벼운 보급/기술 확장은
구현하지 않았다. 주요 항구 보너스는 기존 교역 선박 수입과 독립된 거점
운영 수입이며 새 수도 연결 보정/육상 보급망 시스템은 추가하지 않았다.

Node `>=24.15.0 <25`, npm `>=12.1.0 <13`을 사용한다. 저장소 루트에서 실행한다.

```sh
npm run inst
npm run build-prod
npm run preview:fork
```

브라우저에서 `http://localhost:9002/`를 연다. 메인 화면의 현대 국가 모드에서
독립 지역 규칙을 선택하고 시작한다. Q/W/E 또는 화면 버튼으로 군종을 선택한
뒤 부대와 목표를 지정한다. 전용 교육은 도움말의 챕터에서 시작한다.
개발·초대 방 검증에는 `npm run dev`를 사용하며 공개 외부 계정 API의 신규
개발 없이 loopback 개발 로비를 실행할 수 있다.

검증 명령은 기존 `npm run lint`, `npm test`, `npm run build-prod`다.
Windows의 위 여섯 POSIX 전용 suite 제외는 결과 표의 제한이며 모든 환경에서
`npm test`가 통과했다는 의미가 아니다. 자료 재생성과 원본 의존성은
[자료 문서](ModernRegions.md), 측정 환경·seed·CLI 인자는
[실측 보고서](benchmarks/modern-v2/REPORT.md)에 기록했다.
