# 고정 원본 기준의 디자인 소스 검토

비교 기준은 `e02eeba66b4801ebae0b686e1b0e4bc03fbf3654`이며,
보고된 포크 커밋 `36d5ddebc37e1a731dadca9912ea39d0992297c8` 이후의
복구 작업 트리를 읽기 검토했다. upstream의 다른 버전을 비교 기준으로
사용하지 않았다. 이 문서는 소스 차이의 독립 검토이며, 실제 동일 장면의
가림·가독성·아이콘 크기 검증을 대신하지 않는다. 새 브라우저 증거와 제한은
[복구 검증](ModernRepairVerification.md)과 [UI 검증](RepairUI.md)에 있다.

`ThemeProvider.structureColors()`의 반복 상한과 gamut 포화 시 흰색/검은색
fallback은 앞선 색상 결함 수정으로 남아 있다. 현재 소스에서 이 결과는
`PlayerView`에 저장되지만 실제 호출 소비자는 발견하지 못했고, GL 시설 렌더러는
기존 `RenderSettings`의 색·명암 계산을 사용한다. 따라서 이것을 현재 시설
아이콘 전체의 흑백 재디자인 또는 화면 변화의 증거로 해석하지 않았다.

원래 전역 `OpenFront`/Inter/Arial 폰트 설정은 그대로다. 신규 수도·명령 캔버스의
작은 주석은 11/12px sans-serif를 사용한다. 이는 기존 지도 이름 폰트를 바꾼
것은 아니지만, 같은 글꼴이 화면에서 동일하게 렌더되었다는 판정은 소스만으로
내리지 않는다. 신규 패널의 펼친 상태, 작은 화면의 안내, 기후 overlay를 모두
켠 상태의 가림도 실제 비교가 없는 항목은 미검증으로 남긴다.

검토 명령은 `git diff <fixed-base> -- <paths>`와 `rg`로 원래 자산·render
경로, 기존 HUD/메뉴, 정상 모드의 mount 조건·기본 상태·스타일·소비 경로를
확인했다. 이 검토에서 추가 simulation·UI 동작 변경은 하지 않았다.

후속 태블릿 검증에서 드러난 저장 관리 진입 문제는 `PlayPage.ts`의 기존
`actionButton` 표현과 `ReplayRegularIconWhite.svg`를 재사용하여 현대 모드
버튼 아래에 배치하는 방식으로 수정했다. 이전의 독립적인 파란 현대 버튼도
같은 원본 버튼 컴포넌트로 통합한다. 저장 메뉴의 닫기가 원래 정보 hover에
가리는 문제는 `SavePanel.ts`의 쌓임 순서를 안내·정보보다 위인 1002로 올리는
CSS 변경으로 처리한다. 신규 Port 배치 미리보기는 원본 Port SVG를 실제 native
유효 해안에 반투명으로 보여준다. 모두 기능의 진입·배치·가림 결함에 필요한
차이이며 원래 에셋을 수정하지 않는다. 실제 수정 후 클릭·DPR 판정은 통합
브라우저 기록을 따르고 이 소스 검토만으로 통과시키지 않는다.
