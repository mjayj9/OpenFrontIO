# 현대 지역 v2 사용 및 클라이언트 검증

메인 화면의 현대 국가 모드에서 본국을 고릅니다. 큰 본국은 독립 지역 목록이 이어지며 각 지역의 실제 면적, 중심지, 기후 적응, 주요 항구와 면적 예외를 확인할 수 있습니다. 지도 클릭과 이름 검색도 지원합니다. 분할 지역은 같은 본국이어도 서로 독립적으로 통치합니다. v2의 모든 인간·AI는 설정한 공통 시작 인구와 예산을 사용합니다. 기존 v1 저장은 해당 규칙을 유지합니다.

## 군종과 명령

- Q / W / E는 육군 / 해군 / 공군 선택 모드를 바꿉니다. 군종 버튼도 같은 기능을 합니다. 저장한 기존 키와 충돌하면 기존 키를 우선하고 새 기본 키는 해제합니다. 패널에서 현대 키를 변경하거나 해제할 수 있습니다.
- 좌클릭은 가까운 내 부대를, 드래그는 영역 안의 현재 군종 부대를 선택합니다. Shift는 선택에 추가합니다. 패널의 부대 목록과 모두 선택도 사용할 수 있습니다.
- 우클릭은 명령 미리보기를 엽니다. 경로, 대략적인 도착 시간·위험, 지상전의 기후 보정과 한 타일 손실 추정을 확인하고 실행 버튼을 누릅니다. 예측은 이후 전선과 병력 변화까지 확정하지 않습니다.
- 게임을 일시정지한 동안에도 미리보기를 확인할 수 있습니다. 실제 군사 명령·생산·훈련·항구 개발과 복구는 게임 재개 뒤 실행합니다. 멈춘 동안 누른 실행이 나중에 자동 전송되지는 않습니다.
- Shift+우클릭은 예약 명령입니다. 공군의 예약 출격 미리보기는 실제 기지를 기준으로 하며 앞선 임무의 귀환·재출격 대기 뒤 시작합니다. 정지·취소·대기는 선택한 부대에만 적용됩니다.
- 모바일에서는 군종·부대 버튼을 누르고 목표 선택 버튼 다음 지도 위치를 터치하여 같은 미리보기와 실행을 사용합니다. 두 손가락으로 지도를 확대·이동합니다.
- 국가 정보 버튼 다음 지도 위치를 선택하면 기존 국가 정보와 외교 메뉴를 엽니다. 데스크톱에서는 Ctrl/Meta+우클릭도 가능합니다.

비행장 건설은 버튼 다음 내 통행 가능한 육지를 선택하고 가격·인력 조건을 확인해 실행합니다. 생산할 공군의 출격 거점을 비행장 목록에서 선택할 수 있습니다. 해군 생산은 소유한 실제 완성 항구를 사용합니다. 공군은 영토를 점령하지 않습니다.

## 인구·기후·항구·핵

펼친 군종 패널에서 민간·가용·육군·해군·공군·사망 인력과 실제 미편성 육군 예비 인력을 확인합니다. 기후 오버레이와 적응 훈련은 같은 중앙 게임 규칙을 사용합니다. 주요 항구 목록에는 현재 소유자·수입·개발·피해·봉쇄·복구 상태가 표시됩니다. 개발과 복구는 공통 비용과 게임 tick으로 처리합니다.

핵 건설 메뉴와 발사 준비 화면은 현재 책임 페널티 및 추가 발사의 수입·보충 감소, 지속 시간과 상한을 표시합니다. 요격되어도 발사 책임이 남고 MIRV 한 번 발사는 한 번의 책임입니다. 실제 핵 비용·사거리·재장전은 기존 무기 규칙을 사용합니다.

## 선택형 실습

도움말의 현대 지역·인구·군종 명령·공군·기후·주요 항구·핵 비용·AI 챕터를 선택하면 해당 기능이 활성화된 실제 v2 싱글플레이를 시작합니다. 모든 세력의 시작 인구·훈련 자원 조건은 같습니다. 읽음과 실제 성공, 건너뜀은 별도로 저장합니다.

게임 안에서 다른 현대 챕터를 선택하면 그 챕터의 전용 훈련 시나리오를 시작합니다. 현대 다시 실습도 실제 초기 상태를 새로 준비하며, 같은 챕터 이어하기는 현재 게임의 교육 기록을 이어갑니다.

기후 전용 실습은 파키스탄으로 시작합니다. 실제 오프라인 기후 경계에서 시작 거점 가까이에 적응한 건조 기후와 비적응 냉대 기후의 인접 육상 전장이 있어 짧게 비교할 수 있습니다. 훈련 상대와 같은 시작 인구·예산을 사용합니다.

항구 전용 실습은 포르투갈로 시작합니다. 스페인의 주요 Vigo 항구가 인접 국경에 있어 육군의 실제 점령과 개발을 실습하고 주변 항구에서 접근하는 적 군함의 봉쇄에 대응합니다.

완료 조건은 독립 통치권·동일 인구 확인, 실제 군종 선택·이동·정지 응답, 비행장 생성·출격·귀환·요격 손실, 적응/비적응 실제 지상 손실 비교와 훈련 완료, 항구 점령·개발 수입·봉쇄·수입 회복, 실제 핵 책임 및 AI 정보 확인입니다. 핵 과정은 훈련 예산으로 가능한 원자폭탄을 사용합니다. 안내 확인만으로 군사 실습을 완료하지 않습니다.

교육 버전은 3이며 이전 버전의 성공·건너뜀 기록을 보존합니다. 실제 유효한 키, 비활성 유닛과 설정, 저장된 교육 증거를 참조합니다. `FeatureRegistry`와 공개 스키마의 대응은 `EducationCoverage.test.ts`에서 검사합니다.

## 저장과 리플레이

현대 군사·인구·항구·기후·핵·AI 상태는 기존 게임 상태 업데이트에 포함됩니다. 클라이언트 리플레이 인코더는 변경 없는 keyframe에도 마지막 현대 상태를 보존합니다. 되감기·탐색은 기록된 상태를 복원하고 읽기 전용 군종·비행장·항구 오버레이를 렌더링합니다. 리플레이에서 실제 명령을 전송하지 않습니다.

새 v2 싱글플레이 ID는 `MR` 접두사를 사용하므로 같은 seed의 기존 v1 `MW` 게임 저장을 재사용하지 않습니다. 실제 게임 저장의 파일 관리와 호환성 규칙은 기존 싱글플레이 저장 시스템을 따릅니다.

같은 seed의 새 판은 같은 게임 ID를 만들 수 있으므로 자동 저장은 저장 전용 판 식별자와 빌드로 구분합니다. 한 판의 자동 저장은 갱신하고 새 판의 이전 자동 저장은 보존합니다. 이어하기는 원래 판 식별자를 유지하며 옛 저장에 식별자가 없으면 새로 배정합니다. 이 식별자는 시뮬레이션의 seed나 판단에 사용되지 않습니다.

## 클라이언트 회귀 검사

다음 검사는 UI 증거·명령 전송·입력 맥락·교육·리플레이 codec을 확인합니다. 실제 브라우저 플레이 및 전체 core 결과는 통합 검증 보고서에서 구분하여 기록해야 합니다.

```text
npx vitest run tests/client/ModernInput.test.ts tests/client/ModernCommandPanel.test.ts tests/client/ModernWorldStart.test.ts tests/client/ModernLobbyStartButton.test.ts tests/InputHandler.test.ts tests/EducationCoverage.test.ts tests/Tutorial.test.ts tests/client/TutorialPanel.test.ts tests/client/replay/codec/ModernSystems.test.ts tests/EnJsonSorted.test.ts tests/TranslationSystem.test.ts
```

현대 영문·한국어 추가 번역은 `resources/education/modern-v2.en.json`, `modern-v2.ko.json`을 수정하고 `npx tsx scripts/mergeModernTranslations.ts`로 교육·실행 사전을 재생성합니다. 키를 재귀 정렬하고 실제 오류는 `modern_v2.reason`을 공유합니다. 지리 이름과 원본 면적 보고서는 시나리오 데이터이며 출처·라이선스 링크는 국가 선택 화면에 표시합니다.
