# 현대 모드 실제 플레이 복구 검증

작업 브랜치: `feature/strategic-ai-modern-world`. 시작 시 checkout과 기존
[draft PR #1](https://github.com/mjayj9/OpenFrontIO/pull/1)의 head는
`36d5ddebc37e1a731dadca9912ea39d0992297c8`, 고정 디자인 비교 base는
`e02eeba66b4801ebae0b686e1b0e4bc03fbf3654`였다. 이번 수정의 근거는 새 실행이다.
이전 보고서의 테스트 개수·교육 완료·브라우저 기록을 복구 성공으로 재사용하지 않는다.
런타임 변경·새 후보의 통과·미달·미실행을 아래에서 구분한다.

검증 후보 `64a4a035a0e4`에서는 정상 메뉴로 시작해 육해공의 실제 이동,
세 유료 기지·생산, 데스크톱 공군 5개 실습과 터치 지도 지휘 12개 실습을
완료했다. 이후 core `84bebb823344`의 새 실행에서는 native Port의 잘못된 배치
거절·실제 타일 보정·5초 유료 완공을 확인하고, 같은 빌드 저장·이어하기의
상태 동일성을 다시 확인했다. 저장 패널 가림과 고DPR 실제 클릭도 후속 client에서
검증했다. 최종 client `index-BQUAIhRR.js`에서는 같은 빌드 저장·파일 이어하기·
실제 후속 이동·리플레이 앞뒤 이동·재시작 초기화를 다시 확인했다. 게시 commit은
core와 구별하여 기록한다. 최종 mixed 두 표본의 p95 증가는8.60%/9.40%지만
이전 low/전체 모드의 미달과 최종 low/high 미실행을 남겨, 모든 조건의20% 목표가
해결됐다고 보고하지 않는다.

변경은 현대 기능에 필요한 군종·기지·지휘 추가, 재현된 입력·성장·상태 전달
결함 수정, 요청하지 않은 우상단 파란 패널·문자 마커 복구로 구분했다.

가이드는 새 기능 및 기존 조작 대상 가림 해소 때문에 추가된 차이다.

## 사용과 전체 조작

메인 **현대 국가 모드 → 독립 지역 규칙 → 본국/지역 → 시작**.
육해공은 이 기본 규칙에서 제공한다. 별도 legacy world v1은 기능 범위를 표시한다.
키를 모르면 자원 HUD 아래 **육군/해군/공군 → 기지·생산**을 사용한다.
기지를 지도에서 선택하거나 **B/건설 메뉴**에서 건설한다. Port는 교역 항구이자
해군 생산·보충 거점이고 고유 주요 항구 보너스를 복제하지 않는다.

기존 외교·공격 비율·시설·표시·저장·리플레이·터치·수식키를 포함한
**전체 104 action 표**는 [최종 조작표](RepairKeybindings.md)에 있다.
게임 H, 설정의 키 탭, 현대 가이드 전체 조작표는 같은 registry와 **현재 유효 키**를 읽는다.
재지정은 즉시 반영하며 미지정도 표시한다. 리플레이의 [/]는 프레임 이동,
Shift+[/]는 100프레임 이동이고 군사 명령은 실행하지 않는다.

옛 저장 형식은 변경 의도를 기록하지 않아 기본값과 같은 명시적 변경을 완전히
구별할 수 없다. 충돌하지 않는 사용자 키와 Classic 프로필을 보존하고 현대 필수
키와 충돌한 항목은 백업·변경 사유·수정 경로를 표시한다. 새로운 수정은 충돌을
거절한다. 기존 설정 복사 경로로 다시 Q/W/E 충돌을 만들지 않는다.

새 프로필과 실제 UI에서 저장한 옛 Classic Q/E/W·사용자 X/V 프로필로
현대 진입을 확인했다. Q/W/E가 군종만 전환하고 카메라·명령은 함께 실행되지
않았다. Q→Z 재지정 후 실제 버튼·가이드·도움말이 Z로 갱신됐다. 전체 입력
검사와 재지정·검색의 한글 Unicode 입력 기록은 [입력 검증](RepairKeybindings.md)에
있다. OS의 실제 한국어 IME 전환은 실행하지 않았으며 composing 가드 검사와
구별한다. 핵 키는 목표 준비만 하고 실제 발사는 기존 확인 경로를 사용한다.

10 tick = 1 게임초. N0=1,000,000, 일반 시작 금 400,000과 공통 동원 10%는 유지한다.
전용 실습은 공개된 모든 세력 동일 금 4,000,000을 사용한다. 초기 육군은
기존 1,000명을 500명×2로 나누며 새 인구를 지급하지 않는다.

출처와 예외는 기존 시나리오 문서의 정책을 따르고 이번 수정을 세계 데이터
재검증으로 보고하지 않는다. 신규 싱글플레이·연습은 외부 계정 API 개발 없이
실행한다. 계정·통계·상점의 저장소 밖 코드를 수정했다는 주장도 하지 않는다.

## 남은 검증 범위

- **성능 조건별 판정:**최종 paired4회의 mixed 두 표본은20% 안이다. 이전9회 mixed2+20.60%/low+28.18%와 전체v1/v2 차이는 미달로 유지한다. 최종 low/high·모든 규모를 다시 측정하지 않아 일괄 목표 달성으로 보고하지 않는다.
- **자동 검증과 실제 플레이의 구분:**native Port 거절·실제 배치·완공과 SavePanel1002 실제 클릭은 새 실행에서 확인했다. 확정 사이 소유권/가격 변경 race는 자동 회귀로 검증했고 실제 race 플레이는 미실행이다. 최종 도움말 문자열·게시 client의 재시작/리플레이는 위 실제 결과와 source 단계에 기록했다.
- **원인 미확정:**오래 반복한 자동화 CLI 세션의 Continue 후 안정화/CDP timeout. 새 프로필 공개 이어하기는 성공했고 core 무한 루프는 재현되지 않았다. 자동화/렌더/OS 원인을 해결했다고 주장하지 않는다.
- **환경상 미실행:**POSIX 배포 셸6파일, 실제 온라인 인간 초대·두 클라이언트 재접속/권한 전환, 외부 계정 API 기능, 실물 모바일·OS 한국어 IME 전환, GPU/느린 기기 렌더 p50/p95·고DPR 실물 화면.
- **이번 범위 밖 측정:**30seed 통제 승률·시작위치 교환·장기 교착·모든 국가/기후/해협/AI 수의 성능·전투 비교. 기존 데이터와 규칙 보존·core 회귀 통과를 이 전수 플레이 성공으로 바꾸지 않는다.
- **디자인 비교 제한:**같은 viewport의 원본/수정 자료가 있으나 같은 terrain 소유·시설·부대 장면의 완전한 비교는 아니다. 모든 테마·기후 overlay·모달 조합의 가림도 미실행이면 통과로 표시하지 않는다.
