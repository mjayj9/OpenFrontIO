## 마지막 기후·항구 실습

PAK의 첫 건조 전투 미리보기는 공격 효율 110%, 한 타일 공격 손실 87 raw /
방어 손실 20 raw였다. 실제 교전 후 적응 전투 증거가 증가했다. 첫 공격이
냉대 후보 국경까지 점령하여 새 육군을 실제 공통 인력으로 편성하고 전선으로
이동했다. 이후 적 극지 국경 611428에서 효율 90%, 공격 손실 92 raw /
방어 손실 29 raw 미리보기와 실제 손실을 확인했다. 두 전투는 동일 상대·같은
1000명 편성이나 시간이 지난 다른 위치이므로 통제된 성능 비교 표본으로
사용하지 않는다. 양측 기후 보정 및 실제 계산 일치는 별도 core 회귀가 검사한다.
극지 훈련 완료 tick은 7076, 관찰 tick 7593에서 적응 `arid, polar`, 완료 수 1,
교육 2단계 모두 `practiced`였다. 실습 속도는 기본 ×1이다.

PRT 육군은 Vigo 530951을 실제 점령했다. `captureCount=1`, 이전 소유자
`region0099`에서 `region0204`로 바뀌었다. 75000금/200tick 개발 뒤 1단계
수입은 200/초였다. 상대의 유료 실제 군함이 봉쇄하여 수입이 50/초로 감소했다.
공통 예산으로 군함 3척(12000금·승조원 100명씩)을 생산한 뒤 적 함대 소멸과
봉쇄 해제, 수입 200/초 회복을 확인했다. 이어 실제 물 경로로 Bilbao를
봉쇄했다. Bilbao의 소유권은 상대에게 남았으며 `blockadedBy=region0204`,
내 해군 완료 임무 수 3이었다. tick 5046에서 항구 4단계가 모두 `practiced`,
건너뜀 0이었다.

## 모바일과 화면

실제 touch 활성 Chromium 390×844에서 군종 버튼은 부대 자동 출격 없이
군종만 바꿨다. 지도 터치 선택 → 목표 버튼 → 유효 이동 경로 → 확정 → 실제
이동 → 정지 확인으로 4개 명령 단계가 완료됐다. 두 접점의 실제 touch 이벤트로
카메라가 약 19.4px씩 이동했으며 부대 선택/명령은 유지됐다. 섬에 육군 이동을
시도했을 때 실제 `no_owned_land_path` 이유가 나왔고 명령을 보내지 않았다.
최종 빌드의 인구 실습도 같은 모바일 환경에서 실제 상륙 손실로 완료됐다.

데스크톱 명령 패널은 오른쪽, 기본 순위표는 왼쪽에 있어 군종 버튼을 가리지
않았다. 패널을 접으면 뒤쪽 지도 목표를 직접 지정할 수 있었다. 일시정지 중
유효 미리보기를 확정해도 실제 명령/생산을 보내지 않고 재개 안내를 표시했다.

텍스트 입력·IME 조합·저장 키 우선순위·Q/W/E 카메라 충돌은 입력 회귀로
검사했다. Windows 한국어 IME의 실제 OS 조합 입력 및 사용자 키 재설정의
브라우저 전체 흐름을 별도로 재현했다고 보고하지 않는다.
