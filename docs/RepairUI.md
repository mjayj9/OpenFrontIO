## 찾고 사용하는 경로

일반 현대 국가 모드의 새 규칙으로 시작합니다. 원본 자원 HUD 바로 아래의 육군·해군·공군 버튼은 아이콘, 이름, 현재 유효 키, 살아 있는 부대 수와 선택 상태를 표시합니다. **기지·생산**을 누르면 현재 군종의 기지 선택, 인력·금·시간·용량·완료 대기와 복구를 확인합니다. 지도에서 현재 군종 기지를 눌러도 해당 선택 패널을 엽니다.

**건설 메뉴** 버튼 또는 B로 원래 건설 메뉴를 엽니다. 육군·공군 기지는 원래 건설 카드와 같은 버튼·금 아이콘·가격 표시를 사용합니다. 원래 항구는 해군 기지 역할을 함께 안내하고 교역과 항구 업그레이드를 유지합니다. 별도 항구나 주요 항구 보너스를 복제하지 않습니다. 건설 불가 지형·비소유·자금 부족·기지 한도는 카드 비활성 및 툴팁으로 알립니다. 생산에는 실제 기지 완료와 core의 자금·인력·용량 검증을 적용합니다.

세 새 에셋은 `AircraftIconWhite.svg`, `ArmyBaseIconWhite.svg`, `AirbaseIconWhite.svg`입니다. 기존 아이콘에 맞춘 흰색 실루엣·어두운 윤곽의 SVG이며 `/resources/LICENSE`의 CC BY-SA 4.0으로 제공됩니다. 기존 이미지 파일은 수정하지 않습니다. 초기 육군 기지는 공군 기지와 가능하면 다른 유효 육지 타일에 놓아 찾기 쉽도록 합니다. 인구나 시작 병력을 더 지급하지 않습니다.

## 선택과 경로

1. Q/W/E 또는 해당 군종 버튼을 누릅니다. 선택만으로 출격하지 않습니다.
2. 내 부대를 좌클릭하거나 좌드래그로 상자 선택합니다. Shift는 기존 선택에 더합니다. F와 화면 버튼은 화면 안의 현재 군종 부대를 선택합니다.
3. 커서를 지도에 옮깁니다. 각 선택 부대의 실제 위치에서 유효한 목적지까지 약간 휘어진 화살촉 있는 점선이 나타납니다. 잘못된 목적지는 커서 근처와 HUD에 이유를 표시합니다.
4. 우클릭은 일반 이동·공격을 바로 확정합니다. Shift+우클릭은 경유 명령을 대기열에 추가합니다. core가 검증한 대기 경로는 옅은 짧은 점선과 순서 번호로 구별합니다. 옛 저장에 경로가 없으면 번호만 표시합니다.
5. 진행 중인 실제 core 경로는 실선으로 남습니다. 육군 공격 마커는 실제 점령 전선, 함선 위치는 native Unit 업데이트, 항공기 위치는 실제 편대 상태를 사용합니다. 해군과 수송에 겹치는 가짜 부대를 생성하지 않습니다.
6. X는 정지입니다. Esc는 미리보기·배치·선택 취소입니다. 일시정지 중 미리보기는 가능하지만 눌렀던 명령을 재개 뒤 자동 발송하지 않습니다.

곡선은 실제 통행 경로의 모서리를 보존합니다. 변형한 곡선이 비통행 지형을 지나는지 반 타일 간격으로 검사하고, 불가능하면 해당 구간을 원래 직선으로 표시합니다. 육지·바다 길을 임의로 직선으로 대체하지 않습니다. 월드 좌표를 저장하고 매 프레임 기존 `TransformHandler`로 CSS 화면 좌표를 계산하므로 확대·이동·캔버스 위치 변경과 DPR에 같은 변환을 사용합니다.

커서 요청은 합쳐서 한 번에 한 배치만 Worker에 보냅니다. 오래된 응답은 revision으로 버리고, 확정한 우클릭 목적지는 이후 커서 움직임이 바꾸지 못합니다. 경로 형상은 제한된 캐시에 보관하고 렌더 프레임에서 simulation 상태를 바꾸지 않습니다. 종료 시 이벤트·타이머·RAF·canvas·캐시를 정리합니다.

## 실제 좌표 전달과 리플레이 복구

기존 전체 ModernSystems HUD 갱신은 10 tick(게임 1초) 간격이었습니다. 항공기의 실제 위치가 그 사이 크게 변해 화면에서 순간 이동처럼 보이는 경로를 발견했습니다. 전체 국가·인구·항구 상태를 매 tick 복제하지 않고, 변경된 부대의 실제 위치·단계·경로 인덱스·인력·항공기·공격 전력·전선을 10Hz 압축 정수 프레임으로 Worker에서 전달합니다. renderer는 이 값으로 표시하며 전투·경제·AI 판단을 바꾸지 않습니다.

View는 경제 전체 상태의 tick과 별도로 최근 부대 프레임 tick을 추적합니다. 뒤늦은 옛 전체 상태가 실제 부대를 옛 위치로 돌려놓지 못하며, 아직 전체 상태에 나타나지 않은 새 부대 인덱스는 다음 기준 프레임에서 받습니다. 변경된 부대만 복사하여 이전 리플레이 프레임을 변조하지 않습니다. Binary replay는 이 정수 배열을 직렬화하고, seek 가능한 keyframe에 최신 부대 상태와 별도 ordering tick을 보관합니다.

22:49~22:51 KST 새 검사: ModernCommandPanel, ModernMapDisplay, ModernBuildMenu, 기존 GameView, ModernSystems binary codec 5파일 77개 PASS; 수정 파일 ESLint 및 전체 tsc PASS. 신규 실제 좌표·전선·파괴·늦은 기준 프레임·새 인덱스·chunk 뒤로 이동 검사가 포함됩니다. 이 검사 수는 사용자 경험 완료 판정이 아니며 브라우저 기록은 최종 새 빌드에서 별도로 확보합니다.

production preview를 재사용하며 빌드를 교체하면 RenderHtml의 옛 assetManifest cache가 신규 SVG 경로를 /images/...로 잘못 fallback하는 것도 확인했습니다. preview HTML 요청에서 manifest cache를 갱신하여 새 HTML과 자산 해시가 일치하도록 수정했습니다. static manifest에는 신규 자산 3개가 정상 생성되어 있습니다.
